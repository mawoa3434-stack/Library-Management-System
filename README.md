## Features
- Admin Login
- Student Registration and Login
- Book Management
- Student Management
- Issue and Return Books
- Fine Calculation
- Fine Report and Payment
- Admin Dashboard
- Student Dashboard

## Technologies Used
- Python
- Django
- HTML
- CSS
- SQLite

## Installation
1. Clone the repository:
   git clone https://github.com/mawoa3434-stack/Library-Management-System.git

2. Open project folder:
   cd Library-Management-System

3. Install packages:
   pip install -r requirements.txt

4. Run migrations:
   python manage.py migrate

5. Start server:
   python manage.py runserver
